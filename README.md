
# Wimbo Backend

A Laravel backend for a music streaming website.

---

## About Wimbo

Wimbo is a music streaming application where users can discover, search, listen to, and like songs.

The backend is built with Laravel and will provide the API and database functionality for the frontend.

## Features

- User access to the music library.
- Search for songs.
- Stream and listen to songs.
- Like songs.
- Admin-only song uploads and management.

## Technology Stack

- PHP
- Laravel
- MySQL
- REST API
